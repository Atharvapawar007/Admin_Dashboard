# Admin Dashboard

A responsive **Admin Dashboard** built using **HTML** and **CSS** as part of **The Odin Project** curriculum.

The project recreates a modern dashboard layout using **CSS Grid** and **Flexbox**, featuring a sidebar, header, project cards, announcements, and trending sections.

---

## Features

- Responsive dashboard layout using CSS Grid.
- Fixed sidebar navigation.
- Modern header with:
  - Search bar
  - Notification icon
  - User profile
  - Action buttons
- Project cards displayed in a responsive grid.
- Announcements panel.
- Trending section placeholder.
- Clean typography using the Roboto font.
- Minimal and modern UI inspired by real-world admin dashboards.

---

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox

## Layout Overview

The dashboard is divided into three primary sections:

### Sidebar

Provides quick navigation to various sections of the application.

Navigation includes:

- Home
- Profile
- Messages
- History
- Tasks
- Communities
- Settings
- Support
- Privacy

---

### Header

The header contains two sections.

#### Top Section

- Search bar
- Notification icon
- User profile
- Username

#### Bottom Section

- Greeting message
- Large profile avatar
- Action buttons:
  - New
  - Upload
  - Share

---

### Main Content

The main dashboard consists of three panels.

#### Your Projects

Displays project cards containing:

- Project title
- Project description
- Action icons
  - Favorite
  - Watch
  - Share

Projects are arranged using a responsive two-column CSS Grid.

---

#### Announcements

Displays important updates including:

- Site Maintenance
- Community Share Day
- Updated Privacy Policy

Each announcement is visually separated for improved readability.

---

#### Trending

A placeholder section reserved for displaying trending users, projects, or activity.

---

## Design Highlights

- CSS Grid used for the overall page structure.
- Flexbox used for internal component alignment.
- Clean spacing and consistent typography.
- Soft shadows and rounded corners.
- Material-inspired color palette.
- Responsive layout with flexible sizing.
- Uses Josh Comeau's CSS Reset for consistent styling across browsers.
